# License supplement

`alloc-stdlib` 0.2.4 declares BSD-3-Clause but its crates.io archive omits the
license text. `alloc-stdlib-0.2.4-LICENSE` is the unchanged repository license
from the crate's `.cargo_vcs_info.json` revision:

https://github.com/dropbox/rust-alloc-no-stdlib/blob/ae42d22078b98549e987d2f03d12df7b984fde47/LICENSE

`scripts/prepare_bundled_recorder.py` includes it alongside license texts from
the other resolved dependencies. No dependency source code is modified.
