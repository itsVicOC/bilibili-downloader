# Fluent Design 精修规范

本分支采用 Fluent 2 的层级、材质和交互细节，保留 BiliFlow 的粉紫／青蓝配色、小流、工作区导航及功能流程。界面继续使用 PySide6；没有新增 UI 框架、配置迁移或业务接口变更。

## 第五轮：目录、任务反馈与来源确认（未发布）

下载与批量确认卡保持 72px，路径按文本宽度布局，32px「修改目录」按钮紧随其后，间隔 8px，伸缩留白放在按钮之后。长路径允许压缩，完整文本仍可选择、复制和悬停查看；背景图库预览共用宽度计算。

任务中心三个页签采用整行中性悬停，包含进度、按钮与树形缩进。颜色为内容表面与 4% 正文色混合，优先级为选中、悬停、默认；只更新受影响行，不写模型、不改变选择、不新增动画或轮询。菜单打开时保留所属行反馈。

录制历史的「更多」与右键菜单按整场移除记录，保留所有文件，状态栏提供撤销；下载队列与录制历史的撤销分别保存。录制、重连、收尾或等待／执行导出的目标不可移除。

前台剪贴板识别默认开启，提示在工作区右上方浮动，最大宽度 480px，边距至少 16px，不占布局高度、不抢焦点。内容包括来源类型、数量、摘要与「解析／忽略」；有现有输入时明确显示「替换并解析」。确认前不联网、不修改输入，不自动加入队列。事件使用 150ms 单次防抖，隐藏、最小化、后台、模态窗口、菜单及更新安装期间暂停。仅桌面入口启用，普通测试和截图不读取系统剪贴板。

本轮增加兼容字段 `clipboard_monitor_enabled`，旧配置默认开启，其他配置、数据库结构、窗口记忆和版本标签保持兼容。实现、截图与平台范围见[第五轮验收](FLUENT_V5_VALIDATION.md)。

## 第三轮：信息层级与空间利用

当前开发分支采用横向作品摘要、双列规格与紧凑附加内容列表。下载页在实际内容宽度达到 800px 时将规格与附加内容按 3:2 并排，否则上下排列；规格区内部达到 440px 时使用两列。解析后的来源卡自然高度约 68px，作品标题最多绘制两行，完整文本保留在提示中。

下载与设置共用 40px 附加内容行，明确显示复选框、名称和格式；“全部字幕”缩进置于字幕行下方。设置保存栏固定为 56px，下载与直播确认区继续为 72px。任务中心将移除完成和缓存清理收进工具栏“更多”，行内更多菜单保留移除记录；工具栏空间不足时将操作放到第二行。

普通内容边界、行分隔和表头采用更轻的中性色；浮层与确认区使用独立边界参数。正文和表单标签为 14px，作品标题 18px；背景资源、材质缓存、窗口适配和业务流程沿用现有实现。截图、测试与跨平台边界见[第三轮验收](FLUENT_V3_VALIDATION.md)。

## 第四轮：高度适配与窗口记忆

主窗口客户区低于 800px 时使用紧凑布局，达到 824px 后恢复舒适布局；首次按当前高度判断。共享布局策略由实际控件与背景预览共同使用，保留字段值、选区与焦点。

| 项目 | 舒适 | 紧凑 |
| --- | --- | --- |
| 页面边距／卡片内边距／分组间距 | 24／16／16px | 16／12／12px |
| 下载封面 | 最大 176×99px | 128×72px |
| 下载规格标签 | 字段上方 | 字段同行 |
| 控件与底栏 | 40／44／32px，确认区 72px，设置保存栏 56px | 保持相同尺寸 |

保存目录仅在确认区展示，支持选择、复制和跳转下载设置。成功及普通信息使用固定状态栏，约八秒后消失；移除记录的撤销入口同时保留在任务更多菜单。错误和警告留在相关区域，长诊断使用 Qt 原生可展开、可复制的滚动详情。

窗口状态单独原子写入用户数据目录的 `ui-state.json`，移动／缩放后合并延迟 500ms，隐藏、退出和更新重启前立即保存。记录正常窗口几何与最大化状态，恢复时检查屏幕工作区、负坐标和窗框；最小化／全屏不会成为下次启动状态。桌面入口默认启用，嵌入式宿主、普通测试和截图工具不启用。只保存主窗口，不改变业务配置和更新回滚快照。

实现与平台验证见[第四轮验收](FLUENT_V4_VALIDATION.md)。

## 视觉参数

| 项目 | 规范 |
|---|---|
| 页面／卡片内边距 | 24／16 个逻辑像素 |
| 分组／字段／组内间距 | 16／12／8 |
| 控件／卡片圆角 | 8／12 |
| 普通／主要／紧凑操作高度 | 40／44／32 |
| 下载附加选项高度 | 40，单行展示名称、格式和勾选标记 |
| 下载／直播确认区、设置保存栏 | 72／56，始终显示且状态变化不改变高度 |
| Windows 窗口按钮 | 三个连续的 46×32 逻辑像素热区；矢量图标按实际 DPI 对齐 |
| 正文／说明 | 14／12 个逻辑像素；保留原生中文字体和平台 DPI 换算 |
| 页头／作品标题／分组标题／弹窗标题 | 18／18／16／24 个逻辑像素 |

`UiMetrics` 和 `ThemePalette` 是公共样式及自绘控件的共同来源。新增的内部表面参数包括弱边框、控件底色、悬停层、弱选中层、浮层和语义状态底色。品牌色主要用于主要操作、活动状态和选中指示。表格保留列结构，百分比移到细进度条上方，避免文字跨越不同颜色的填充区域。

第二轮精修将普通悬停、按下状态改为中性色层，卡片边线与行分隔分别使用独立弱描边；规格标签按内容宽度居中，避免整列色块。菜单与页签保留轻选中背景，品牌色集中用于指示线和主要操作。按钮与页签都区分鼠标操作和键盘焦点，状态变化不改变几何。

普通控件使用细边框；主要按钮预留两像素的透明焦点边框。焦点、按下、只读和禁用状态不改变控件的占用尺寸。鼠标点击与自动激活不显示键盘焦点框；键盘焦点仍清晰可见。macOS 的 Tab 遍历遵循系统“完整键盘控制”偏好。

粉色主要操作参考 [B 站官网样式](https://s1.hdslb.com/bfs/static/shanks/laputa-home/assets/index-3f345f9f.css)：日间使用 `Pi5 #FF6699`、悬停 `Pi4 #FF8CB0`、按下 `Pi6 #E84B85`，搭配 `text_white #FFFFFF`；夜间使用官网深色阶 `Pi5 #D44E7D`，悬停与按下分别取 `Pi6 #DC6D94`、`Pi4 #A73E65`。这是用户确认的品牌配色选择，粉色主按钮不计入普通正文 4.5:1 的对比度保证；青蓝主要操作仍保持 4.5:1。

文本选区使用独立的 `text_selection`／`text_selection_text` 参数，不复用导航和表格的弱选中底色。粉色主题日间／夜间为 `#AD1C5B`／`#A73E65`，青蓝为 `#007FAF`，均搭配白字；选区文字对比度至少 4.5:1，底色与输入框至少 2:1。Qt 调色板与输入框、富文本、纯文本及可编辑组合控件共享该规范。

## 材质与布局

保留用户已有的背景图片、分区可见度及模糊参数。玻璃缓存降低饱和度、提高中性色融合比例，并弱化折射边缘与高光；文字和控件不进入模糊缓存。无背景时使用统一实色表面，有背景时页签保留不透明底色，避免底图影响文字。

设置中的默认媒体规格在可用宽度达到 860 个逻辑像素时采用两列，窄窗口回到单列。直播时长列按字体宽度计算，完整显示超过 99 小时的时间。已有的侧栏收窄、下载表单重排、直播详情折叠与背景图库小窗口模式继续生效。macOS 保留原生窗口按钮，Windows 使用应用自绘按钮；快捷键、托盘行为和文件选择器的平台差异保留。

Windows 主窗口采用 `FramelessWindowHint` 与 Win32 非客户区适配，在同一 QWidget 绘制链路中绘制按钮和页头，替换此前的 Qt 分层标题栏裁剪补丁。默认底色使用同一 `background` 参数，最小化／最大化悬停为中性色，关闭悬停／按下分别为 `#C42B1C`／`#A1261B`，配白色图标。最大化显示还原图标；热区边界按实际 DPR 统一取整，允许分数缩放下相邻宽度相差一个物理像素。

Win32 保留系统菜单、任务栏和可缩放窗口样式；空白页头返回 `HTCAPTION`，边缘返回相应缩放命中，最大化按钮返回 `HTMAXBUTTON`。按下／释放共用一个状态处理，捕获丢失时取消操作，关闭进入既有 `closeEvent` 与托盘／退出流程。最大化依据当前显示器工作区，坐标按原生客户区换算，不假设主显示器原点。依据：[微软自定义边框](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe)、[Windows 11 Snap 接入](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-snap-layout-menu)。

窗口状态切换由 `ShowWindow` 驱动，避免 Qt 无边框窗口仅改变尺寸而未设置原生最大化状态；`WM_SIZE` 将状态同步回 Qt。最大化客户区排除 Windows 放在工作区外的不可见缩放边框，保证标题栏按钮完整显示。关闭图标使用按物理像素对齐的实线，避免 100% 缩放时斜线的抗锯齿覆盖率降低对比度。

## 更新说明与背景资源

更新说明使用只读 `QTextBrowser` 和 Qt GitHub Markdown 解析，覆盖标题、列表、强调、引用、代码、表格与链接。解析后设置块、字符和表格格式，主题切换保留选区和滚动位置；长内容换行并在阅读区内滚动。网页链接经系统浏览器打开，文档锚点在阅读区内定位；图片替换为描述或显式链接，不自动请求网络或本地文件。默认弹窗为 680×520，最小 480×360，并约束在屏幕可用区域。

十二景保留原有 ID 和资源路径。本轮使用内置 imagegen 编辑四张原图的手部，同步导出背景、缩略图与总览；其余八张资源保持不变。手部检查和修图提示词见 [背景手部复核](BACKGROUND_HAND_REVIEW.md)。

## 微动效

导航选中指示与下载选项状态使用 120ms 过渡，折叠箭头使用 160ms，均采用 OutCubic 缓出。折叠内容、校验定位、页面切换和业务操作立即生效。

动画以 Qt 数值动画驱动局部重绘，不逐帧重设样式表、不增加轮询。重复操作从当前数值转向最终状态；隐藏、禁用或切换主题时结束当前动画。截图工具通过进程内 `uiAnimationsEnabled=False` 关闭过渡，保证截图可重复；此开关不写入用户配置。

离屏验证覆盖两套配色、深浅模式和三种尺寸，以及无图、内置图片、自定义图片；正文和状态文字按至少 4.5:1 的对比度检查。已有的下载、直播、登录、草稿、更新、缓存、文件选择器和窗口生命周期回归继续运行。新增测试检查动画快速反转、隐藏／禁用后停止、焦点几何稳定及背景页签的实际绘制颜色。

QT_QPA_PLATFORM=offscreen python -m pytest -q
