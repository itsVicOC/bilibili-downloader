# 故障排查

## 应用无法启动

### macOS 提示无法验证开发者

当前 Release 未进行 Apple 公证。在“系统设置 → 隐私与安全性”中找到拦截提示并选择“仍要打开”。请确认安装包来自本仓库 Release 页面。

### Windows Defender 或 SmartScreen 提示未知应用

预构建包尚未购买商业代码签名证书。核对 Release 来源和文件名后，可通过“更多信息”选择运行。不要从第三方下载站获取重新打包版本。

### 源码启动提示 `PySide6 not installed`

确认已激活虚拟环境并安装项目依赖：

```bash
python -m pip install -c constraints.txt -e ".[dev]"
python -m bilibili_downloader
```

## FFmpeg 不可用或合并失败

full 包应直接使用应用内置 FFmpeg。若 full 包仍提示不可用，请重新完整解压、核对 `SHA256SUMS.txt`，并确认安全软件没有隔离应用内的 `ffmpeg` 或 `ffmpeg.exe`。

lite 包和源码运行先检查：

```bash
ffmpeg -version
```

如果终端可用但应用仍找不到，请在“下载设置”中选择 FFmpeg 可执行文件。Windows 应选择 `ffmpeg.exe`，不要选择安装目录。设置中的自定义路径会覆盖 full 包的内置版本；清空该项即可恢复使用内置版本。

合并失败时确认输出目录可写、磁盘空间充足，并避免其他程序占用同名目标文件。HEVC 或 AV1 下载不要求系统播放器能解码，但播放时需要对应解码支持；兼容性优先可选择 AVC/H.264。

需要判断输出文件是否完整时，可以让 FFmpeg 解码全部音视频流而不生成新文件：

```bash
ffmpeg -v error -i "输出文件.mp4" -map 0:v:0 -map 0:a:0 -f null -
```

命令无输出且退出码为 0 表示所选音视频流可以完整解码。仅音频文件删除 `-map 0:v:0`。

## 无法解析链接

- 首页解析框支持 BV 号、AV 号、视频详情页 URL 或 b23.tv 短链。
- 合集、系列和收藏夹请使用“批量导入”；需要账号权限的收藏夹应先登录。
- 番剧播放页、课程、稍后再看、直播和动态页面目前不支持。
- b23.tv 需要联网展开；代理、DNS 或公司网络可能阻止跳转。
- 浏览器能打开但应用失败时，稍后重试并确认系统时间准确。

错误提示会区分登录失效、权限不足、内容不可用、平台风控和网络故障。遇到风控或限流时不要连续重试，应降低并发并等待一段时间；遇到登录或权限提示时，重新登录并确认当前账号可在浏览器中访问该内容。

## 看不到高画质或指定编码

应用只显示接口实际返回的流。1080P+、4K、HDR、Dolby Vision 和 8K 通常要求登录、会员权限、视频本身提供对应规格，且不一定同时提供 AVC、HEVC、AV1。

重新登录并解析后仍不存在，表示当前账号或视频没有该规格。应用不会绕过平台权限。

## 登录失败

- 手动登录只填写 `SESSDATA` 的值，不要粘贴整段 Cookie 请求头。
- SESSDATA 可能过期，退出网页账号后旧值也可能失效。
- 扫码接口可能因 Bilibili API 变化临时不可用，可改用手动方式。
- Linux 无 Secret Service 时会回退到本地配置。安装并解锁系统密钥环可恢复安全存储。

切勿在公开 Issue 中提供真实 Cookie。

## 下载中断或速度异常

- 重试会优先复用可续传临时文件，并在主链接失败后尝试备用 CDN。
- Bilibili 偶尔返回使用非标准端口的 mcdn 主地址；应用会保持 HTTPS 安全限制并自动尝试标准端口的备用 CDN。
- CDN 是否支持 Range、链接是否过期以及网络代理均会影响续传。
- 将并发数降低到 1–3，排除带宽、磁盘或服务器限速。
- 输出目录位于网络盘或同步盘时，先改到本地磁盘验证。
- 磁盘空间预检失败时，先释放提示所需空间；合并阶段需要同时容纳断点流和最终文件。

## 重启后任务状态异常

- 正在下载或合并的任务会恢复为“已暂停”，点击“继续”后重新获取流地址并复用断点。
- 如果记录存在但媒体文件已被移动，“打开”会提示文件不存在；可清除该完成记录。
- `tasks.sqlite3` 保存任务历史，`.biliflow-parts/` 保存媒体断点，两者用途不同。
- 删除任务记录不会删除媒体文件；“清理缓存”会永久删除未完成断点。
- 版本升级需要调整任务库结构时，应用会先创建 `tasks.sqlite3.bak`，迁移失败不会覆盖原任务库。
- 如果完整性检查确认任务库已损坏，应用会将其隔离为 `tasks.corrupt-<时间>.sqlite3` 并创建空库；状态栏会显示隔离文件名。保留该文件用于排查，不要用新库覆盖它。
- 任务库若由更新版本创建，当前版本会拒绝修改。请使用创建该数据库的版本，或先备份整个配置目录再处理。

## 合集或收藏夹只解析出部分内容

- 私密收藏夹和账号专属内容需要先登录，并确保当前账号仍有访问权限。
- BiliFlow 会持续读取分页，单个来源超过安全分页上限时会停止并显示错误。
- 已存在的同源作品仍可勾选，不同画质或音频模式可以建立新任务；完全相同规格会在加入时跳过。

## 字幕或弹幕缺失

字幕和弹幕必须由对应视频实际提供。部分字幕轨需要登录权限；弹幕关闭、视频无字幕或接口未返回轨道时不会生成文件。

媒体已经生成但某个附加项缺失时，任务会显示“部分完成”。这表示主媒体可用，不需要重新下载视频；根据警告内容确认该视频是否实际提供对应字幕或稍后单独重试。

## 配置损坏

应用会把无法解析的配置备份为同目录的 `config.json.bak` 并恢复默认设置。配置目录在 macOS 为 `~/Library/Application Support/BiliFlow`，Windows 为 `%APPDATA%\\BiliFlow`，Linux 为 `$XDG_CONFIG_HOME/biliflow`（默认 `~/.config/biliflow`）。若问题持续，关闭应用后移动 `config.json`，再重新启动配置。

报告仍未解决的问题时，请按 [CONTRIBUTING.md](../CONTRIBUTING.md) 提供环境、复现步骤和已脱敏日志。
