# 晴海主题：调研与取舍

调研日期：2026-10-18。参考 B 站当前首页实际界面及其公开样式，另对照下载中心、直播首页。以下是本项目的主题适配，不代表 B 站官方客户端设计规范。

## 核对到的官方色板

首页加载的样式标注为 `@bilibili/b-style v5.0.0`，包含 `:root` 与 `html.bili_dark` 两套变量。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 品牌蓝 `Lb5` | `#00AEEC` | `#0087BD` |
| 白色表面 `Wh0` | `#FFFFFF` | `#17181A` |
| 页面底色 `Ga0` | `#F6F7F8` | `#101011` |
| 正文 `Ga10` | `#18191C` | `#E7E9EB` |
| 辅助文字 `Ga7` | `#61666D` | `#A2A7AE` |
| 常规分隔线 `Ga2` | `#E3E5E7` | `#2F3134` |
| 蓝色浅底 `Lb1` | `#DFF6FD` | `#0B202A` |

官网首页以白色和中性灰呈现导航、分区和内容，蓝色用于登录、链接与选中状态。直播首页公开样式也以白色表面为主，使用 `#23ADE5` 及相邻蓝色表现交互。下载中心采用白底和中性灰文字，说明各业务页面并非统一铺满蓝色。

## 第二版调整

- 使用官方中性色组织页面、侧栏、卡片和次级按钮；移除第一版遍布界面的蓝灰底色。
- 深色采用中性炭灰，替换第一版海军蓝底色；品牌色按官方深色色阶降低亮度。
- 蓝色主题的输入横幅改为纯色卡片，移除圆形、斜线和渐变装饰。页签采用透明底和蓝色下划线，输入边框减为 1px，保留原有控件总高度。
- 品牌强调色与带文字的主按钮分开。主按钮使用白字，为达到正文 4.5:1 对比度，将填充适度加深为 `#007FAF`；悬停和按下继续加深。官网品牌蓝配白色小字不能达到同一对比度目标，因此没有逐色照搬。
- 保留自定义背景功能，用自动遮罩保护裸露在图片上的正文和辅助文字；默认主题预览单独展示，避免将演示壁纸误认为默认配色。
- 本次用实际 Qt 界面渲染迭代；页面由原生控件、语义色板和矢量绘制组成，无需新增位图设计素材。

## 第三版：晴海

第二版的纯色横幅与透明页签过于平淡。本轮保留上述官方中性色与可读主按钮，在少数区域增加层次：横幅使用从白色 / 炭灰过渡至浅青 / 深青的天空渐变，右侧叠加柔粉微光和低透明度波纹，顶部用细渐变线收边；侧栏收藏卡片采用同系渐变。选中导航的蓝色浅底向右淡出，页签采用浅青底与下划线，其他内容卡片继续保持清晰底色。

2026-10-19 页头调整：将上述天空渐变、柔粉微光和波纹从链接输入卡移至全宽工作区页头。左侧标题区保持纯色，装饰向右侧集中；输入卡恢复与资料卡相同的实体表面和细边框，让装饰层级更集中。星河主题同步将粉紫渐变和星轨上移，深浅色、布局尺寸与现有主题选择保持兼容。

两套主题的显示名改为「星河」「晴海」，设置下拉项的提示说明配色方向。配置仍使用 `star_trail`、`bilibili_blue`，已有选择不受改名影响。
