# 0.8.11b1 字幕来源与 4:3 本机验收

本机测试版本：0.8.11b1，macOS arm64，full 完整包。基于 `codex/subtitle-provenance-aspect` 工作区构建；未发布正式版本，未替换 `/Applications/BilibiliDownloader.app` 中的 0.8.10。Qt 保持 PySide6 6.11.1。

以下记录为 beta 发布前的本机验收；跨平台发布检查以 GitHub Release 工作流结果为准。`v0.8.11b1` 属于预发布版，正式版通道仍为 `v0.8.10`。

## 字幕来源与文件保留

- 使用签名 `/x/player/wbi/v2`，返回 BV/AV、CID 必须与请求一致；缺少身份或轨道 ID 时拒绝保存字幕。
- 每个发布成功的字幕记录内容身份、CID、轨道 ID、协议版本及 SHA-256。中文、英文和全部语言使用同一套校验。
- 没有来源记录或内容被修改的旧字幕显示“待重新获取（旧字幕未核验）”。补全附件复用视频，转换完成后原子替换字幕；旧文件保存在相邻 `.unverified.bak`，重名自动编号。
- 回归覆盖接口身份不符、AV 身份绑定、旧错误字幕刷新、全部语言、仅一种语言可用、失败保留与重试、已核验文件复用、哈希变化及复制期间文件变化。诊断记录只包含视频身份、CID、语言、轨道 ID 和协议版本，不包含 Cookie 或签名字幕 URL。

## 4:3 输出与无损验证

GUI 视频输出新增“显示比例”；默认保持原始，纯音频禁用。CLI 支持 `--aspect-ratio original|4:3`。比例进入任务、重复检测、归档匹配和输出记录；旧记录默认原始比例。

4:3 使用 `-c copy -aspect:v:0 4:3`，保存独立 `.4x3.mp4`，保留原视频。匹配的本地原始媒体优先用于另存，已核验字幕使用副本的对应名称。此行为修改容器显示比例，不裁剪或重新编码；依据 [FFmpeg 官方文档](https://github.com/FFmpeg/FFmpeg/blob/master/doc/ffmpeg.texi)。

H.264 和 HEVC 合成样本分别验证：

- 输出像素尺寸仍为 1920×1080，ffprobe 报告 DAR 为 4:3。
- 视频、音频的全部压缩数据包 SHA-256 与原始媒体一致；原始文件哈希不变。
- 新下载合并路径、本地另存路径、字幕复制、归档复用及取消均通过；已有同名视频与封面不会被覆盖。
